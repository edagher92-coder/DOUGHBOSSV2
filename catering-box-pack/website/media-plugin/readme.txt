Image files for the DoughBoss Growth Catering Box plugin. No code, no settings, no requests.

== Description ==

This plugin carries only image files (AVIF, WebP, JPEG and PNG) and assets/box/manifest.json. It does nothing by itself. The DoughBoss Growth Catering Box plugin reads the manifest to decide what may be shown.

Phase 1 holds concept artwork and concept renders of the box (no food) and two small brand devices. Every concept image is shown with a visible "Concept preview" label.

Version 0.2.0 adds the first-frame pictures (WebP, 1080 and 720 wide) of the home hero video in assets/hero, with hero.json. The hero video and its pictures show AI-generated food as a concept; that was the owner's decision on 3 October 2026 and the page labels it. The five MP4 files are not in this zip because the host caps an upload at 2 MB: upload them under Media, Add New.

To change the images later, upload a newer zip of this plugin under Plugins, Add New, Upload Plugin and choose "Replace current with uploaded". No code release is needed.

== Installation ==

1. Upload the zip under Plugins, Add New, Upload Plugin, then activate. Activate this plugin before the Catering Box plugin.
