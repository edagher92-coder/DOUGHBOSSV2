# DoughBoss authentic photography manifest — 9 August 2026

## Release direction

Release 2.34.0 replaces the generated floating-food homepage composition and repeated menu lookalikes with real DoughBoss merchant photography. Management confirmed that DoughBoss owns, or has permission to use, the promoted images.

The visual rules are:

- Present food as oven-baked; never describe or stage it as wood-fired.
- Map a photograph only when it represents the exact named product.
- Never use a similar-looking product as a substitute.
- Show the branded “Real product photo coming soon” state when an exact approved photograph is unavailable.
- Preserve natural dough texture and colour; avoid fake smoke, impossible levitation, excessive saturation and burnt-looking edits.

## Approved production set

The homepage hero uses `public/images/doughboss-feast-real-v1.jpg`. Exact menu assets are versioned under `public/images/menu/real-v1/` and mapped by `DoughBoss_REST_Controller::menu_image_url()`.
