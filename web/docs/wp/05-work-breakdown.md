## 0. Rules every package inherits

1. **Working trees.** The lead creates, with Elie's approval, two writable git worktrees; agents never run git themselves and never write in `/tmp/wp-src/*` (read-only references).
   - `<growth-wt>`: new branch from `claude/live-2.41.0-baseline` (76deb569); companion work lives only in `<growth-wt>/doughboss-growth/`, `<growth-wt>/doughboss-growth-media/` and `<growth-wt>/.github/workflows/growth-ci.yml` (`00 §3.9`).
   - `<core-wt>`: new branch from `codex/release-readiness-20260908` (1600a399, PR #68 head) for core 2.44.0.
   - `web/` = `/home/user/DOUGHBOSSV2/web/` (current branch). Never run `npm install` there; use the existing `web/node_modules/.bin/{esbuild,acorn,tsx,vitest}` read-only.
2. **Constraints (binding):** PHP 7.4+ syntax (no `match`, nullsafe, typed properties, arrow functions, `str_contains`); WordPress 6.0+ APIs only; hand-written front-end JS is ES5 syntax (IIFE, `'use strict'`, `var`, `textContent`), checked with `acorn --ecma5`; every feature defaults **off**; fail closed; secrets env/constant first, never printed, logged or committed; no provider or live-site request; WordPress-core coding style (tabs, Yoda, `array()`, `$wpdb->prepare`, capability **and** nonce on every admin handler, `ABSPATH` guard, `final class` + `init()`).
3. **No competing writers.** The companion never writes a core table, option, post type, role or capability. Core 2.44.0 is the only writer of orders, payments and Square configuration.
4. **Evidence.** Each package ends with a short hand-off note in its own `docs/` file inside its owned paths listing what was run (commands and pass counts), what was not, and any `[CONFIRM]` gap. No claim of "works" without a test or a rendered check.
5. **Shared contracts are frozen by WP-01 and this file.** A package that needs a contract change stops and asks the lead rather than editing another package's files.
6. **Test layout.** Each package owns `tests/test-<module>.php`, `tests/<module>.test.js` and `tests/fixtures/<module>-*.json` for its module; `tests/bootstrap.php` and `tests/run.php` belong to WP-01. Browser checks go in `web/scripts/wp-local/growth/<wp-id>-<topic>.mjs` (one file per package, Playwright resolved from `web/node_modules`, pattern of `web/scripts/wp-local/shots.mjs`).
