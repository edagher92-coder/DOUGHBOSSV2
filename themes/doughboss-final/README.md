# DoughBoss Final WordPress theme

Production presentation theme for doughboss.com.au. The theme matches the approved dark editorial demo while delegating all operational data and actions to the DoughBoss plugin.

## Safety contract

- No menu prices, cart totals, payment state or order state are owned by the theme.
- The DoughBoss plugin supplies menu, shop, cart, tracking, catering and animated food components.
- When `ordering_open` is off, the theme omits builder and checkout surfaces and shows the browse-only coming-soon state.
- Local plugin images and self-hosted fonts are used; no third-party font service is required.
