# Themes captured from production (2026-09-07)

`doughboss-final/` is the **active** theme on doughboss.com.au (v1.4.0, no parent),
captured from the same UpdraftPlus backup as the plugin. It is committed here so the
storefront's templates are version-controlled alongside the plugin they render.

Also present on the server but not committed (inactive): `doughboss` 1.0.0,
`doughboss-child` (3.4 MB, child of `doughboss`), `doughboss-hybrid` 0.1.1, two
`doughboss-child-wpvibe-backup*` copies, `blockify`, and ten stock/demo themes.
